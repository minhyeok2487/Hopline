## 설치

1. [최신 릴리스](https://github.com/minhyeok2487/Hopline/releases/latest)에서 `Hopline-<버전>.zip`(예: `Hopline-0.9.1.zip`)을 받아 원하는 폴더에 압축을 풉니다. 안에 `Hopline.exe` 하나가 들어 있고, 설정은 파일 이름·폴더와 상관없이 유지됩니다. `.exe` 다운로드가 허용되는 환경이면 `Hopline-<버전>.exe`를 바로 받아도 됩니다.
2. 압축을 푼 폴더(예: `C:\Tools\Hopline\`)에서 `Hopline.exe`를 실행합니다. 설치 과정은 없습니다.
3. 아직 코드 서명이 없어서 처음 실행할 때 Windows SmartScreen이 *"Windows의 PC 보호"* 경고를 띄울 수 있습니다. **추가 정보 → 실행**을 누르세요. 실행 전에 릴리스 페이지의 SHA-256 값과 파일을 비교해 볼 수 있습니다.

Hopline은 Microsoft Edge WebView2 런타임이 필요합니다. Windows 11과 최신 Windows 10에는 기본으로 들어 있습니다. 앱이 켜지지 않으면 [WebView2 Evergreen 런타임](https://developer.microsoft.com/microsoft-edge/webview2/)을 설치하세요.

삭제할 때는 Hopline 실행 파일을 지우면 됩니다. 저장된 데이터까지 지우려면 [데이터 위치](../README.ko.md#데이터-위치)에 있는 폴더도 지우세요.

## 처음 접속하기

가장 빠른 방법은 창 위쪽의 **빠른 접속**입니다.

1. `user@host` 또는 `user@host:port`(텔넷은 `telnet 주소[:포트]`)를 입력하고 **Enter**를 누릅니다.
2. 비밀번호를 묻는 창에 입력합니다. 빠른 접속은 세션으로 저장되지 않습니다.

접속하는 동안 탭에 **접속 중** 카드가 경과 시간과 **취소** 버튼과 함께 나타납니다. 그래서 응답 없는 장비 때문에 창이 멈추지 않습니다. 연결이 끊기면 탭 아래쪽에 **재접속**(또는 **Enter**)과 **탭 닫기** 버튼이 나옵니다.

## 세션 저장과 정리

세션 패널의 **+**로 새 세션을 만들거나, 기존 세션을 우클릭해 **연결, 편집, 복제, 삭제**를 고릅니다.

![세션 우클릭 메뉴](screenshots/guide-session-menu.png)

![SSH 세션 편집](screenshots/guide-session-editor.png)

| 항목 | 설명 |
|---|---|
| 이름 | 목록과 탭에 표시됩니다. 비우면 호스트명을 씁니다. |
| 폴더 | 기존 폴더를 고르거나 경로를 입력합니다. `/`로 구분하면 하위 폴더가 됩니다(`본사/서버실`). |
| 호스트, 포트, 사용자 | 포트 기본값은 22입니다. |
| 비밀번호 | 비우면 접속할 때마다 물어봅니다. **비밀번호 저장**을 켜면 암호화해서 저장합니다(아래 참고). |
| 개인키 | 선택 사항. OpenSSH나 PEM 형식 키 경로(`id_ed25519`, `id_rsa` 등). PuTTY `.ppk`는 먼저 변환해야 합니다. |
| 종류 | SSH, **텔넷**(포트 23. 사용자 이름과 비밀번호를 저장하면 로그인 프롬프트에 자동 입력. 텔넷은 암호화되지 않음), 시리얼 |
| 구형 알고리즘 허용 | 오래된 스위치·방화벽에서만 쓰는 예전 키 교환·암호 방식(예: `diffie-hellman-group1-sha1`, CBC)을 허용합니다. 최신 장비에서는 끄세요. |

요령:
- 세션을 더블클릭하거나, 선택하고 **Enter**를 누르면 접속합니다. **F2**는 편집입니다.
- **세션 검색**에 입력하면 이름·호스트·사용자·폴더로 걸러지고, 방향키로 고를 수 있습니다.
- 세션 옆 초록 점은 열린 탭이 있다는 뜻입니다(`●2` = 탭 2개).

**폴더**

- **+** 옆의 폴더 버튼을 누르거나, 빈 곳을 우클릭해 **새 폴더**를 고릅니다. 빈 폴더도 만들 수 있고 폴더 안에 폴더를 둘 수 있습니다.
- 세션을 폴더로 **끌어다 놓으면** 옮겨지고, 빈 곳에 놓으면 최상위로 나옵니다. 폴더도 같은 방법으로 다른 폴더 안에 넣을 수 있습니다. 세션 우클릭 → **폴더로 이동…**으로 목록에서 골라도 됩니다.
- 폴더를 우클릭하면 **이 폴더에 새 세션, 새 하위 폴더, 폴더 이름 바꾸기, 모두 접속, 모든 폴더 접기/펼치기, 폴더 삭제**가 있습니다. 폴더를 지워도 세션은 지워지지 않고, 안의 세션과 하위 폴더는 한 단계 위로 옮겨집니다.
- 폴더를 클릭하면 접히고, 접어 둔 상태는 다음에 켜도 유지됩니다. 검색하면 접힌 폴더 안의 세션도 보입니다.
- 빈 화면에 **최근 접속** 목록이 나와 클릭 한 번으로 다시 접속할 수 있습니다.

## 인증과 호스트 키

**저장된 비밀번호**는 Windows DPAPI로 내 Windows 계정에 묶어 암호화한 뒤 `%APPDATA%\Hopline\data.json`에 저장합니다. 다른 Windows 사용자나 다른 PC에서는 복호화할 수 없습니다.

**암호가 걸린 개인키:** 접속할 때 비밀번호 입력 창에서 키 암호를 물어봅니다.

**호스트 키(처음 접속 시 신뢰):** 처음 접속한 서버의 키를 `%APPDATA%\Hopline\known_hosts`에 저장하고, 터미널에 지문을 노란색으로 표시합니다.

나중에 장비가 다른 키를 보내면 Hopline이 멈추고 **SSH 호스트 키가 바뀌었습니다** 창에 저장된 지문과 새 지문을 보여 줍니다.

- **접속 안 함**(기본 선택, Enter도 이쪽): 아무것도 바꾸지 않습니다. 키가 바뀐 이유를 모르면 이것을 고르세요. 누군가 연결을 가로채고 있을 수 있습니다.
- **새 키 신뢰하고 접속**: 장비를 다시 설치했거나 교체한 경우(실습용 VM, RMA 교체, Gaia 재설치 등)입니다. known_hosts에서 그 장비의 예전 줄만 새 키로 바꾸고 접속합니다.

아래쪽 상태 표시줄에 현재 연결, 터미널 크기, 진행 중인 전송, 멀티 실행 상태, MCP 서버 실행 여부가 표시됩니다.

## SFTP 파일 패널

사이드바의 **SFTP** 탭을 엽니다. **현재 활성 SSH 탭**의 연결을 그대로 써서 파일을 보여 주므로 따로 로그인할 필요가 없습니다.

![SFTP 패널](screenshots/sftp.png)

- **이동:** 폴더 더블클릭, **↑**로 상위 폴더, 경로의 각 부분 클릭, 또는 경로 막대의 빈 곳을 클릭해 직접 입력합니다.
- **다운로드:** 파일 더블클릭(또는 우클릭 → 다운로드) 후 저장 위치를 고릅니다.
- **업로드:** **업로드** 버튼을 누르거나, 탐색기에서 파일·폴더를 목록 위로 끌어다 놓습니다. 진행률은 목록 아래와 상태 표시줄에 나옵니다.
- **파일·폴더 우클릭:** 이름 바꾸기, 경로 복사, 삭제. 실수로 통째로 지우는 일을 막기 위해 폴더는 비어 있을 때만 지울 수 있습니다.

"SFTP 사용 불가"가 나오면 서버가 SFTP 기능을 제공하지 않는 경우입니다(네트워크 장비에서 흔함).

## 시리얼 콘솔

**종류: 시리얼 (COM)**으로 세션을 만듭니다.

![시리얼 세션 설정](screenshots/guide-session-serial.png)

- **포트** 목록에 지금 Windows가 인식한 COM 포트가 어댑터 이름과 함께 나옵니다. USB 콘솔 케이블을 꽂은 뒤 새로고침 버튼을 누르세요.
- 콘솔 설정은 보통 **9600 8N1**(Cisco 등 대부분의 스위치)이나 **115200 8N1**입니다.
- 포트가 안 보이면 USB-시리얼 어댑터 드라이버(FTDI, Prolific, Silicon Labs CP210x)를 설치하고 장치 관리자에서 확인하세요.

## TFTP 서버

펌웨어 업그레이드나 설정 백업 때 도구 막대의 **TFTP**를 눌러 장비와 파일을 주고받습니다.

- 폴더(기본 `문서\Hopline\tftp`)와 포트(69)를 정하고 **시작**을 누릅니다. 창에 이 PC의 주소와 `copy tftp://<PC>/ios.bin flash:` 같은 Cisco 예시가 나옵니다.
- 장비는 그 폴더 안의 파일만 받아 갈 수 있습니다. 설정 백업을 받으려면 **장비에서 올리는 파일 받기**를 켜세요(`copy running-config tftp://<PC>/backups/sw1-confg`).
- 전송 기록은 창과 알림으로 보입니다. 처음 시작할 때 Windows 방화벽이 물으면 허용을 누르고, 다 쓰면 중지하세요.

## 자동 로그온 (enable, 점프 접속)

세션 편집 창 아래쪽의 **자동 로그온**에 *기다릴 문자열 → 보낼 내용* 단계를 적어 두면, 접속할 때마다 Hopline이 순서대로 입력합니다. SSH와 시리얼 세션 모두 쓸 수 있습니다.

- 화면에 **기다릴 문자열(Expect)**이 나오면 **보낼 내용(Send)**을 입력하고 Enter를 누릅니다. Expect를 비우면 바로 보냅니다.
- **숨김**을 체크한 값(비밀번호)은 Windows 계정으로 암호화되어 저장되고, 편집 창에도 다시 표시되지 않으며 AI에게도 전달되지 않습니다.
- **먼저 Enter 보내기**는 아무것도 출력하지 않고 기다리는 시리얼 콘솔을 깨웁니다.
- 한 단계에서 30초 안에 문자열이 나오지 않으면 멈추고, 몇 번째 단계에서 멈췄는지 터미널과 알림으로 알려 줍니다.

| 용도 | 기다릴 문자열 | 보낼 내용 | 숨김 |
|---|---|---|---|
| enable 모드 | `>` | `enable` | |
| | `assword:` | enable 비밀번호 | ✓ |
| 시리얼 콘솔 로그인 (먼저 Enter 보내기 체크) | `sername:` | `admin` | |
| | `assword:` | 비밀번호 | ✓ |
| 점프 서버를 거쳐 장비로 | `$ ` | `ssh admin@10.0.0.2` | |
| | `assword:` | 장비 비밀번호 | ✓ |

**enable 예시 추가** 버튼을 누르면 위의 enable 두 단계가 들어가고, 비밀번호 칸만 채우면 됩니다. 문자열은 대소문자를 구분하므로 `Password:`와 `password:`를 모두 잡으려면 앞글자를 뺀 `assword:`처럼 적으세요.

## 멀티 실행과 매크로

**멀티 실행**은 입력한 내용을 체크한 모든 탭에 동시에 보냅니다. 여러 스위치에 같은 `show` 명령을 실행할 때 유용합니다.

![두 탭에 멀티 실행](screenshots/guide-multi-exec.png)

1. 필요한 탭을 열고 도구 막대의 **멀티 실행**을 누릅니다. 주황색 테두리가 켜진 상태를 나타냅니다.
2. 탭마다 체크박스가 생깁니다. 입력을 받지 않을 탭은 체크를 해제하세요.
3. 체크된 아무 탭에서나 입력합니다. 상태 표시줄에 대상 탭 수가 나옵니다.

**매크로**는 이름을 붙인 명령 묶음입니다. 한 줄씩 보내고 줄마다 **Enter**를 누르며, 줄 사이에 지연 시간을 둡니다.

![매크로 편집](screenshots/guide-macro-editor.png)

- **매크로** 패널의 **+**로 만들고, 더블클릭하면 편집합니다.
- **실행**을 누르면 현재 탭에 보냅니다. 멀티 실행이 켜져 있으면 체크된 모든 탭에 보냅니다.
- 네트워크 장비라면 첫 줄에 `terminal length 0`처럼 페이지 넘김을 끄는 명령을 넣어 긴 출력이 `--More--`에서 멈추지 않게 하세요.
- 느린 장비나 프롬프트가 늦게 돌아오는 명령에는 줄 간격을 늘리세요.

**명령 버튼 바.** **버튼 바에 표시**를 켠 매크로는 탭 아래 한 줄에 버튼으로 나옵니다. 누르면 현재 탭(멀티 실행 중이면 체크된 탭 전체)에 보내고, **Shift+클릭**은 열린 탭 전체에 보내며, **Alt+1** … **Alt+9**로도 실행합니다. 버튼은 끌어서 순서를 바꾸고, 우클릭으로 편집하고, **+**로 새로 만듭니다. 바는 우클릭 메뉴나 설정 › 동작에서 숨길 수 있습니다.

- **변수:** 명령에 `{{이름}}`이나 `{{이름|기본값}}`을 쓰면(예: `show interface {{포트|Gi0/1}}`) 실행할 때 값을 묻고, 마지막 값을 기억합니다.
- **보내기 전에 확인:** `write memory`, `reload`처럼 설정을 바꾸는 매크로에 켜 두세요. 보내기 전에 실제 내용과 대상 탭을 보여 줍니다.

## 세션 로그

도구 막대의 **로그**를 누르면 현재 탭 기록을 시작하고, 탭에 빨간 **REC** 표시가 붙습니다. 다시 누르면 멈춥니다.

- **자동 기록:** 설정 › 세션 로그 › *모든 세션을 접속할 때부터 자동으로 기록*을 켜면 접속하자마자 기록합니다. 세션 편집 창의 **자동 기록**(앱 설정 따름 / 항상 기록 / 기록 안 함)으로 세션마다 다르게 정할 수 있습니다.
- **장비별 폴더:** `문서\Hopline\logs\<세션>\<날짜>_<시각>.log`에 저장됩니다. 저장 폴더는 설정에서 바꿀 수 있습니다.
- **깔끔한 텍스트:** 색상 코드를 빼고 백스페이스를 반영해(`--More--`가 남지 않음) 저장하며, 줄마다 `[2026-10-25 14:03:21]`처럼 받은 시각을 붙입니다. 시각이 필요 없으면 설정에서 끄세요.

**보기와 검색.** **로그** 옆 목록 버튼을 누르면 로그 창이 열립니다. 왼쪽은 세션별 목록, 오른쪽은 로그 내용입니다. 입력란에 쓰면 세션 이름을 거르고, **Enter**를 누르면 모든 로그 내용을 검색하며 결과를 누르면 그 줄로 이동합니다. 로그에서 **AI 작업 요약**, 탐색기에서 보기, 삭제를 할 수 있습니다. 탭 우클릭 › **로그 보기**는 그 탭의 로그를 엽니다.

## AI 도우미와 정기 점검

Hopline의 AI 기능은 PC의 [Claude Code](https://claude.com/claude-code)(CLI 또는 Claude 데스크탑 앱에 들어 있는 것)를, 로그인된 계정 그대로 사용합니다. 따로 API 키를 넣을 필요가 없습니다. AI는 Hopline이 보내는 텍스트(화면, 선택 영역, 로그)만 받으며, 스스로 세션에 입력할 수 없고 저장된 비밀번호는 Hopline 밖으로 나가지 않습니다. 설정 › AI 도우미에서 Claude Code를 찾았는지 확인하고 모델을 고를 수 있습니다.

**AI 도우미 패널** (**AI** 버튼 또는 `Ctrl+Shift+A`). 현재 탭에 대해 평소 말투로 물어보세요. *"지금 화면에 이상한 거 있어?"*, *"다운된 인터페이스 보는 명령 알려줘"*. **터미널 화면 함께 보내기**가 켜져 있으면 탭의 최근 화면이 같이 전달됩니다. 답에 있는 명령에는 버튼이 붙습니다.

- **입력**은 Enter 없이 입력만 해서, 확인하거나 고친 뒤 직접 실행할 수 있습니다.
- **실행**은 입력하고 Enter까지 누릅니다. `configure`, `no shutdown`, `reload`, `write`처럼 설정을 바꾸는 명령은 주황색으로 표시되고 **입력**만 됩니다.

탭마다 대화가 따로 유지되고, 새로고침 버튼으로 새 대화를 시작합니다.

**선택한 출력 물어보기.** 터미널에서 출력을 선택하면 옆에 **AI에게 묻기** 버튼이 뜹니다. 누르면 의미, 이상한 점, 다음에 확인할 명령을 알려 줍니다. 쓰지 않으면 설정에서 끌 수 있습니다.

**AI 작업 요약.** 탭 우클릭 › **AI 작업 요약**, 또는 로그 창에서 **AI 작업 요약**을 누르면 요약, 실행한 명령, 설정 변경, 이상 징후, 후속 조치를 짧은 보고서로 정리합니다. 저장된 로그의 요약은 로그 옆에 `<이름>.summary.md`로 남습니다.

**정기 점검** (**점검** 버튼). 고른 세션들에 조회 명령을 매일 정한 시각(예: `08:30, 18:00`), N분마다, 또는 **실행**을 누를 때만 실행합니다.

- Hopline이 켜져 있어야 합니다(트레이도 됨). 꺼져 있어 놓친 실행은 2시간 안이면 이어서 실행합니다.
- 탭을 열지 않고 백그라운드로 접속해 세션의 자동 로그온을 먼저 실행한 뒤 명령을 보내고 연결을 끊습니다. 세션에 비밀번호나 키가 저장돼 있어야 합니다.
- 설정을 바꿀 수 있는 명령은 점검에 저장되지 않습니다.
- 결과는 `문서\Hopline\logs\_checks\<점검>\<실행 시각>\`에 장비별로 저장됩니다. **AI**를 켜면 AI가 결과를 읽고 이전 실행과 비교해 정상 / 확인 필요 / 문제 발견으로 표시합니다. 실행이 끝나면 알림이 뜨고, **결과**에서 요약과 장비별 출력을 볼 수 있습니다.

## 가져오기와 백업

**다른 프로그램에서 가져오기:** 세션 목록 위의 가져오기 버튼(또는 빈 곳 우클릭)을 누르면 이 PC의 MobaXterm, PuTTY, SecureCRT, Xshell 세션을 찾아 SSH·텔넷·시리얼 세션과 폴더 구조를 프로그램 이름의 폴더로 가져옵니다. 내보낸 파일(`.mxtsessions`, SecureCRT `.ini`, Xshell `.xsh`)도 가져올 수 있습니다. 비밀번호는 가져오지 않고, 이미 있는 세션은 건너뜁니다.

**백업:** 설정 › 백업 › **설정 내보내기**로 세션, 폴더, 매크로와 (원하면) 화면 설정을 JSON 파일로 저장합니다. **저장된 비밀번호 포함**을 켜고 백업 암호를 정하면 비밀번호도 암호화해 넣으므로 다른 PC에서 복원할 수 있습니다. **백업에서 복원**은 지금 데이터에 합칩니다.

## AI 어시스턴트 연동 (MCP)

Hopline은 로컬 MCP 서버를 띄워 Claude Code 같은 AI 어시스턴트가 저장된 세션을 탭으로 열고, 명령을 실행하고, 결과를 읽게 할 수 있습니다. 그 과정은 화면에서 그대로 보입니다.

![Claude가 Hopline을 조작하는 모습](screenshots/mcp.png)

**설정**

1. 도구 막대의 **MCP**를 누르고 **Claude Code에 연결**을 누릅니다. Hopline이 서버를 켜고(`127.0.0.1:7781`에서만 열리고 토큰 필요) Claude Code에 등록한 뒤 `hopline` 스킬을 `~/.claude/skills/hopline`에 설치합니다.
   - CLI 없이 Claude 데스크탑 앱만 써도 됩니다. Hopline이 앱에 들어 있는 Claude Code로 등록하고, 앱의 Code 탭에서 hopline을 쓸 수 있습니다.
   - 둘 다 없으면 **Claude용 설정 문구 복사**를 눌러 Claude Code 채팅에 붙여넣으세요. Claude가 등록과 스킬 저장을 대신 합니다.
   - 직접 하려면 **MCP 서버 켜기**를 체크하고 **명령 복사**로 복사한 명령을 터미널에서 한 번 실행합니다.

     ```bash
     claude mcp add --scope user --transport http hopline http://127.0.0.1:7781/mcp --header "Authorization: Bearer <토큰>"
     ```

2. Hopline을 켜 둔 채 새 Claude Code 세션을 열고 요청합니다. 예:
   - *"hopline으로 core-sw01에 접속해서 인터페이스 상태 보여줘."*
   - *"hopline으로 Lab 폴더의 리눅스 서버 디스크 사용량 확인해줘. 조회 명령만 실행해."*

**hopline 스킬**은 Claude가 Hopline으로 장비 작업을 하는 방법을 알려 줍니다. 열린 탭을 먼저 확인하고, 장비 종류를 파악하고, 요청이 없으면 조회만 하고, 설정을 바꿀 때는 정확한 명령을 보여 준 뒤 승인을 받고, 마지막에 요약 표로 정리합니다. Hopline을 업데이트하면 설치된 스킬도 새 버전으로 바뀝니다. 직접 고친 내용을 유지하려면 파일의 `Installed by Hopline` 줄을 지우세요.

**이미 열어 둔 탭 쓰기:** AI가 직접 접속하지 않아도 됩니다. 세션을 직접 열고(시리얼 콘솔이라면 로그인까지 하고) *"지금 보고 있는 탭에서 `show ip interface brief` 실행해줘"*라고 하면 됩니다. `list_tabs`에 연결된 모든 탭이 나오고 앞에 있는 탭은 `(active)`로 표시되며, 모든 탭 도구가 `tab: "active"`를 받습니다. `open_session`도 같은 세션의 탭이 열려 있으면 새로 열지 않고 그 탭을 씁니다.

**화면에서 보이는 것:** AI가 쓰는 탭이 앞으로 나오고, 입력하는 동안 **AI** 표시가 붙습니다. 비밀번호가 저장되지 않은 세션은 Hopline 창에서 **사용자에게** 직접 묻습니다. 저장된 비밀번호는 AI에 전달되지 않습니다.

**도구:** `list_sessions`, `list_tabs`, `open_session`, `run_command`, `run_on_tabs`(여러 장비에 같은 명령을 동시에 실행), `send_keys`, `read_output`, `sftp_list`, `sftp_read_file`, `sftp_write_file`, `sftp_download`, `sftp_upload`, `close_tab`. `run_command`는 프롬프트(또는 `expect` 패턴, 최대 600초)가 나올 때까지 기다리고 `--More--`는 자동으로 넘깁니다.

**안전하게 쓰기**
- 조회만 허용할 때는 AI에게 분명히 말하고, 도구 호출을 승인하기 전에 무엇을 할지 확인하세요.
- 장비 계정은 꼭 필요한 권한만 가진 계정을 쓰세요.
- MCP 창의 **토큰 재발급**은 기존 토큰을 즉시 무효로 만듭니다. 이후 Claude Code에 새 명령으로 다시 등록하세요.
- MCP 서버를 끄면 포트가 닫힙니다.

### 트레이에서 계속 실행

창을 닫아도 Hopline은 종료되지 않고 알림 영역(트레이)으로 숨겨집니다. MCP 서버와 열린 연결이 그대로 유지되므로 창을 닫은 상태에서도 AI가 계속 작업할 수 있습니다.

- 트레이 아이콘을 클릭하거나 Hopline 실행 파일을 다시 실행하면 탭이 그대로 있는 창이 돌아옵니다. Hopline은 한 번에 하나만 실행됩니다.
- 완전히 끄려면 트레이 아이콘을 우클릭해 **종료**를 누르세요.
- 창이 숨겨진 상태에서 AI가 비밀번호가 저장되지 않은 세션을 열면 창이 다시 나와 비밀번호를 묻습니다.
- Windows 11에서는 새 트레이 아이콘이 숨김 아이콘(**^**) 안에 들어갑니다. 작업 표시줄로 끌어다 놓으면 항상 보입니다.
- 설정 › 창에서 **닫기 버튼을 누르면 트레이로 숨기기**를 끄면 닫기 버튼이 종료로 바뀌고, **Windows 시작 시 트레이로 실행**을 켤 수 있습니다.

| *SSH 호스트 키가 바뀌었습니다* | [인증과 호스트 키](#인증과-호스트-키) 참고. 장비를 다시 설치했거나 교체했을 때만 새 키를 신뢰하세요. |
| 오래된 스위치·방화벽에서 *no common algorithm* / 핸드셰이크 실패 | 세션 편집에서 **구형 알고리즘 허용**을 켜세요. |
| *인증 실패* | 비밀번호를 다시 묻습니다. 사용자명을 확인하고, 키 인증이라면 키 경로와 OpenSSH/PEM 형식인지 확인하세요. |
| SFTP 패널: *SFTP 사용 불가* | 서버가 SFTP 기능을 제공하지 않습니다. 터미널을 쓰거나 SFTP를 지원하는 서버를 쓰세요. |
| COM 포트가 목록에 없음 | USB-시리얼 드라이버 설치 → 케이블 다시 꽂기 → 세션 편집에서 새로고침 |
| Claude Code가 hopline에 연결 못 함(*connection refused*) | Hopline이 켜져 있고(창을 닫았다면 트레이에) MCP 서버가 켜져 있어야 합니다. MCP 창의 포트가 등록한 주소와 같은지 확인하세요. |
| Claude Code에서 *401 Unauthorized* | 토큰이 바뀌었습니다. MCP 창에서 명령을 다시 복사해 재등록하세요(`claude mcp remove hopline -s user` 후 추가). |
| AI: *Claude Code가 설치되어 있지 않습니다* | MCP 연동 창 안내대로 Claude Code를 설치한 뒤 AI 패널을 다시 여세요. |
| AI: *로그인이 만료됐습니다* | PowerShell에서 `claude`를 실행해 다시 로그인한 뒤 시도하세요. |
| 정기 점검: *저장된 비밀번호나 키가 없습니다* | 세션 편집에서 비밀번호를 입력하고 **비밀번호 저장**을 켠 채 저장하세요. |
| 붙여넣을 때마다 확인 창이 뜸 | 설정에서 **여러 줄 붙여넣기 전 확인**을 끄세요. |
